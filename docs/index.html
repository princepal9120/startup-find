Why startup-find

Built for developers & AI agents

Everything you need to research the YC and a16z ecosystems — without a single network call after seeding.

🔒

100% Local

All data lives in a SQLite file on your machine. Nothing leaves your computer. No accounts, no telemetry.

⚡

Blazing Fast

Sub-millisecond queries against SQLite. Filter by batch, industry, country, or hiring status instantly.

🤖

Agent-Friendly

Pass --agent for compact JSON stdout. Clean exit codes (0/1/66) for shell scripting and LLM tool use.

🔍

Full-Text Search

Search across company names, one-liners, and descriptions. Pipe results to jq for custom transforms.

🌐

HTTP REST API

Can't use Python? Run startup-find serve and hit a local HTTP server from any language.

📦

Zero Dependencies

Pure stdlib Python 3.9+. No pip chain to break. Optional pyyaml for YAML output.

Commands

Everything at your fingertips

Familiar subcommand patterns. Multiple output formats. Pipe-friendly.

Seed & Setup

startup-find seed
Pull all YC batches from public Algolia into local SQLite
startup-find seed --batch "Summer 2025"
Seed only specific batches (comma-separated)
startup-find seed-a16z
Pull a16z portfolio into the same SQLite database

Query & Filter

startup-find search "ai agent"
Full-text search across all companies
startup-find companies --is-hiring true --industry Fintech
Filter with multiple predicates
startup-find company --slug stripe
Look up a single company by slug or ID

Insights

startup-find stats
Portfolio-wide stats: totals, hiring count, industry breakdown
startup-find batches
List all distinct YC batches in the database
startup-find digest --format json
Daily digest: latest batch, hiring companies

Output Formats

startup-find companies --format table
Human-readable terminal table (default)
startup-find companies --format json --agent
Compact JSON for LLM tool use
startup-find companies --format csv
CSV output for spreadsheets and pandas
HTTP API

Use from any language

Run a local server and access startup data from Ruby, Go, Node, or curl.

$ startup-find serve --port 8731
# Listening on http://127.0.0.1:8731

$ curl "localhost:8731/search?q=ai+agent"
GET/healthLiveness check
GET/statsPortfolio stats
GET/batchesDistinct batches
GET/companiesFilter & paginate
GET/searchFull-text search

Get started

Up and running in 60 seconds

Install from PyPI or clone from GitHub. Zero config.

1

Install

$ pip install startup-find

Or from source: git clone && pip install -e .

2

Seed (one-time)

$ startup-find seed # YC — public Algolia, no key
$ startup-find seed-a16z # a16z portfolio
3

Query offline, forever

$ startup-find search "ai agent" --limit 10 --format json
$ startup-find companies --is-hiring true --batch "Summer 2025"
$ startup-find digest --agent
